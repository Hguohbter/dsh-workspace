# 胖虎快跑 · 夜市跑酷

白天→夜市的轻量网页跑酷：三条弯曲跑道、路边小吃摊、跳台、小电驴。纯静态零依赖，手机直接玩。

线上地址：<https://hguohbter.github.io/dsh-workspace/subway/>

## 操作

| 动作 | 手机 | 键盘 |
| --- | --- | --- |
| 换道 | 左右滑动 | ← → / A D |
| 跳跃（上跳台） | 上滑 / 轻点 | ↑ / W / 空格 |
| 翻滚（钻横幅、广告牌下面没有缝） | 下滑 | ↓ / S |
| 暂停 | 切到后台 | Esc |

## 玩法

- **3 格血**：撞路障/垃圾桶/广告牌掉一格，掉完结算；短时间无敌帧防连撞。
- **小吃**（摊位上的成品）：
  - 香妃卷 +30 分，附护盾（挡一次撞击）
  - 老北京鸡肉卷 +45 分，附 4 秒加速
  - 烤冷面 +35 分，回一格血
- **小电驴**：骑上速度 ×1.65，持续 9 秒；期间撞到东西会摔车（不直接死），有 1.4 秒缓冲无敌。
- **跳台**：木箱 0.82m / 矮墙 1.12m / 台阶 1.05m / 摊位顶棚 1.05m，台面有高光边提示落点。

## 场景与系统

- 跑道沿 `curveAt()` / `hillAt()` 两条正弦叠加的曲线弯曲起伏，所有投影都带曲线/坡度偏移。
- 程序化布置：路边物件间距 6m ± 1.6m，随机偏航 ±0.26rad、缩放 0.9~1.12、4 种变体；路面内容每 13m ± 3m 一行。
- 三层视差天际线 + 高架桥 + 列车剪影 + 暖色地平线光晕；雾用渐变吃掉生成边界。
- 镜头：随速度微调 FOV、换道有横向惯性、撞车有震动。
- 对象池：物件跑出 `dist - 6` 就回收（`world.items` 数组原地裁剪）。

## 怎么加一个新同学

1. 两张白底全身照 → `python scripts/prep-subway-assets.py <id> 正面.jpg 背面.jpg`
2. 在 `app.js` 顶部 `CHARACTERS` 加一条（id / name / face / head / colors / headOffsetX）。
3. 多个角色时开始页会出现头像切换（目前只做了一人，切换行隐藏）。

## 调参

`app.js` 顶部 `CONFIG`：

| 字段 | 作用 |
| --- | --- |
| `speedMin` / `speedMax` / `accel` | 速度曲线 |
| `jumpV` / `gravity` | 跳跃（默认顶点约 1.3m，够上 1.05m 的台子） |
| `lives` | 血量 |
| `invuln` / `hitSlow` | 受击无敌时间 / 减速倍率 |
| `scooter` | 电驴倍率、持续时间、最小间隔 |
| `food` | 三种小吃的分数与效果（`shield` / `boost` / `heal`） |
| `spawn` | 路边间距、行间距、抖动 |
| `lb.topic` | 排行榜 topic，换一个就是空榜 |

## 验证

无头浏览器冒烟测试（需要先起一个 CDP 端点的 Edge/Chrome）：

```bash
node scripts/subway-smoke.mjs
```

它检查：开局血量 3 → 吃小吃加分并拿到护盾 → 护盾挡一次撞击 → 连续撞击后血量归零、结算页弹出。
截图校验用的是 `scratch/` 下的临时脚本（不进仓库）。
